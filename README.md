Repositório dedicado ao armazenamento dos códigos, exercícios e projetos práticos desenvolvidos ao longo do curso **Desenvolvimento Web Completo**, ministrado por **Jorge Sant Ana** e **Jamilton Damasceno** na plataforma Udemy.

## 🚀 Tecnologias Estudadas

- **Front-end:** HTML5, CSS3, SASS, Bootstrap 5, JavaScript (ES6 até ES14), jQuery, Ajax
- **Back-end:** PHP (Orientação a Objetos, PDO, MVC, Slim Framework, APIs)
- **Banco de Dados:** MySQL
- **CMS & Mobile:** WordPress, Ionic
- **Hospedagem:** InfinityFree
